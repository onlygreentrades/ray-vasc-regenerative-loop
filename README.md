# RAY-VASC Regenerative Loop

Speculative open-source neuroplasticity research framework for N-of-1 to cohort implementation, data capture, and publication.

Originated through the care journey of Raymond A. Hornsby and developed by Logan Henderson as the originating researcher.

This repository is designed for lawful, clinically governed implementation, structured data recording, reproducible protocol development, and publication.

## Public Repository Boundary

This public repo may include:
- Protocol frameworks
- Study outlines
- De-identified templates
- Data dictionaries
- Governance documents
- Publication drafts
- Analysis scripts
- Synthetic or de-identified example data

This public repo must not include:
- MRNs
- Full dates of birth
- Addresses
- Raw medical records
- Private clinical screenshots
- Identifiable records without written consent and privacy review

## Controlled-Substance Boundary

The framework includes a controlled-substance research layer only for lawful, clinically governed, regulated, ethics/IRB-appropriate environments.

This repository does not provide sourcing, preparation, dosing, administration, or self-use instructions for controlled substances.

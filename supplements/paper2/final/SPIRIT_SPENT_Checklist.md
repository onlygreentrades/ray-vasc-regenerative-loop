# Paper 2 Reporting-Guideline Supplement

## Purpose

This supplement maps the RAY-VASC protocol manuscript to protocol and downstream reporting standards.

## Standards Covered

- SPIRIT 2025: protocol completeness.
- SPENT 2019: N-of-1 protocol extension requirements.
- SPIRIT-PRO: patient-reported and proxy-reported outcome handling.
- CONSORT-CENT: downstream N-of-1 results reporting.
- TIDieR-style exposure documentation principles.

## Public Boundary

This checklist is a reporting-support document. It does not create clinical instructions, treatment recommendations, or controlled-substance guidance.

## Core Mapping Summary

| Standard | RAY-VASC location |
|---|---|
| SPIRIT 2025 administrative and scientific protocol elements | Paper 2 title page, abstract, objectives, design, setting, eligibility, outcomes, timeline, data management, SAP, safety/ethics, open science |
| SPENT N-of-1 protocol extension | Objectives, comparator rationale, repeated measures, baseline variance, cycle interpretability, within-person analysis, carryover/washout boundary |
| SPIRIT-PRO | PRO/proxy reporting, burden ceiling, PHQ/GAD tiering, ZBI-12, EAT-10, missing data, multiplicity |
| CONSORT-CENT downstream reporting | Individual trajectories, adherence, harms, missingness, phase boundaries, small-series aggregation |

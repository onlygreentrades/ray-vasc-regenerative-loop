# Paper 3 — RAY-001 Baseline Characterization

This folder contains the clean public manuscript files for Paper 3 in the RAY-VASC publication series.

## Public title

RAY-001 Baseline Characterization in a Complex Neurovascular Parkinsonian Phenotype: Documenting Pre-Intervention Architecture and Measurement Feasibility for Future Neuroplasticity Research

## Boundary

This manuscript is a CARE-aligned baseline characterization and measurement-feasibility case report. It does not report intervention outcomes, treatment efficacy, recovery, reversal, repair, cure, or disease-modification claims. Tier 2 EEG, biomarkers, wearables, and APPRE response-policy cycles are described as protocol-specified but not executed for RAY-001.

No raw clinical records, source-lock ledgers, consent files, direct identifiers, portal screenshots, or private clinical reports are included.

# Scripts

The PowerShell files in this directory are historical Paper 4 v0.1.1 maintenance and verification utilities retained for provenance.

## Current status

These scripts predate the published Paper 4 v1.0.0 Figure-Integrated Edition, the public thesis, the current OSF component layout, and the nested APPRE supplement lane.

Do not run them against the current `main` branch without a separate code review.

Current APPRE support assets are located under:

```text
supplements/paper4/final/appre-v0.1.1/
├── analysis/v0.1.1/
├── data/synthetic/v0.1.1/
├── schemas/v0.1.1/
└── validation/v0.1.1/
```

Current public records are maintained in `README.md`, `PAPER_INDEX.md`, `REPO_MAP.md`, `CITATION.cff`, and the Paper 4 release metadata.

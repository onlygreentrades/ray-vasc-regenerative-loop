# OSF Component Text - Paper 4 APPRE v0.1.1

## Component title
APPRE: Schema-and-Rules Framework for Adaptive Measurement and Response-Policy Documentation

## Description
This OSF component contains the public Paper 4 APPRE methods/data-architecture package for the RAY-VASC Regenerative Loop Research Program. APPRE is published as a schema-and-rules framework for repeated-measures organization, confounder annotation, adverse-event documentation, missingness coding, response-policy versioning, provenance, and reproducibility. APPRE is not validated artificial intelligence, not clinical decision support, not a medical device, and not a treatment optimizer. The public package includes the manuscript, schemas, data dictionary, synthetic dataset stubs, validation rules, implementation notes, and reproducibility checklist. No raw identifiable clinical data are included.

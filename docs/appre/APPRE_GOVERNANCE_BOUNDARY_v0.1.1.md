# APPRE Governance Boundary v0.1.1

APPRE v0.1.1 is a research-data architecture and schema-and-rules documentation release.

## Not included in this release

- validated artificial intelligence
- clinical decision support
- Software as a Medical Device
- treatment optimization
- diagnosis
- prescribing
- controlled-substance personalization
- consumer longevity product claims

## Privacy boundary

Public release excludes raw identifiable clinical data, raw medical records, private screenshots, and unapproved individual-level outcome data.

## Implementation boundary

External prospective implementation intended to contribute to generalizable knowledge requires local ethics review, IRB review, or formal determination as applicable, plus consent/privacy/safety governance.

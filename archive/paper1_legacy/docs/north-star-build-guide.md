# RAY-VASC North Star + Build Guide v0.2.0

**Publication-Only Public Research Framework**

Originating researcher: Logan Henderson  
Public scope: research publication, protocol development, open-source documentation, and reproducible data architecture only.  
Commercial scope: no product line, supplement brand, retreat, clinic, or commercial treatment service is part of this repository.  
Status: speculative / hypothesis-generating / publication-stage.

## Executive Directive

RAY-VASC is a public research-publication project. It exists to organize, publish, and open-source the existing research, study protocol, measurement architecture, claim rules, governance boundaries, and analysis pathway behind the Regenerative Loop + APPRE + 3-Phase Plasticity Architecture.

This is not a product-line repository. It does not market supplements, sell services, promote a clinic, operate a retreat, or commercialize a treatment. The only public mission is publication-grade research infrastructure: protocols, forms, schemas, evidence maps, manuscript drafts, analysis tools, and governance files that qualified teams can review, adapt, and improve under lawful oversight.

## North Star

Build the most credible open-source neuroplasticity research framework possible: speculative where the science is early, rigorous where measurement is available, lawful where controlled-substance research is involved, and reproducible enough for external teams to implement without Logan present.

## Operating Standard

- Credibility before virality.
- Protocol before claims.
- Measurement before interpretation.
- Consent before identifiable publication.
- OSF registration before external prospective subject data collection.
- Governance before controlled-substance implementation.
- Open-source structure before scale.
- Publication-grade documentation before public promotion.

## Scope Boundary

Allowed: protocol manuscripts, framework papers, evidence maps, de-identified forms, schemas, analysis scripts, synthetic example data.

Not allowed: product pages, supplement marketing, retreat promotion, commercial treatment claims, clinic sales copy, controlled-substance sourcing/preparation/dosing/administration/self-use instructions, disease cure/reversal claims, or identifiable medical records without consent/privacy review.

## OSF Pre-Registration Trigger

OSF pre-registration must be completed before any prospective data collection from any participant other than self-experimentation. No external subject data enters the repo or analysis pipeline without a pre-registration record number in the file header.

## Version Control Rule

Version increments require a documented reason in CHANGELOG.md. Only Logan Henderson may authorize changes to core governance sections. Other sections may be revised with a changelog entry and commit message that describes the change.

## Commit Standard

Use conventional commit format: `type(scope): summary`.

Examples:

- `docs(protocol): add inclusion and exclusion criteria v0.2`
- `feat(schema): add adverse_event.schema.json`
- `fix(evidence-map): correct evidence grade for Bacopa from A to B`
- `legal(boundary): clarify controlled-substance research layer`
- `privacy(repo): remove identifiable source document from public folder`

## Contributor Qualification Standard

Contributors submitting to protocol, clinical, safety, biomarker, neurophysiology, ethics, or controlled-substance sections must identify themselves with a professional affiliation, role, credential, or relevant expertise. Anonymous pull requests to these sections will not be merged without review and maintainer approval.

## Claim Rules

Allowed wording: hypothesis-generating framework, may indicate a measurable signal, residual capacity hypothesis, lawful clinically governed controlled-substance research layer, as-administered observational exposure field, designed for qualified teams under governance.

Forbidden wording: proven treatment, demonstrates cure, reversal of neurodegeneration, use this substance / dose this way, protocolized unsupervised controlled-substance use, strong evidence where only pilot/preclinical data exist, anyone can implement clinically without oversight.
